# 🏛️ RUNEFORGE V2.6.2 — MANIFESTO DE ARQUITECTURA

## Filosofía del Sistema
- **Local-First:** Cero dependencias de la nube para la operación táctica.
- **Privacidad Radical:** Los datos no salen del dispositivo.
- **Cero Bloat:** Uso de Vanilla JS y Canvas nativo en lugar de librerías pesadas.
- **Estética Cyber-Mística:** Dark mode, acentos neón y Glassmorphism.

## Ecosistema Modular (V25 FINAL)
El Command Center Táctico se compone de 4 módulos integrados en un único HTML offline:
1. **DB (IndexedDB):** Almacenamiento ilimitado de tramas de telemetría.
2. **Charts (Canvas):** Graficación en tiempo real sin librerías externas.
3. **Live (Simulador):** Flujo continuo de datos para pruebas de estrés.
4. **Mapa (Leaflet):** Geolocalización táctica con filtro oscuro.

## Limpieza Forense 2026-10-22
- Eliminados ~15 GB de basura (BuzzStage, OllamaSetup, Backup antiguo de 11.9 GB).
- Consolidación de WhisperTools y TGL-LAB en las rutas canónicas.
