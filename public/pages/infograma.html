FORGE UI V2.0

"De un panel de control estático a un ecosistema de ingeniería de prompts interactivo."

Hardware: GTX 1660 SUPER • LLM: QWEN 2.5 1.5B • Status: Evolution Active

I. Métricas Clave de la Evolución

La transición a la v2.0 no es solo estética; se centra en la reducción drástica de la latencia cognitiva y la optimización del throughput de tokens.

Latencia de Respuesta (ms)

La integración nativa con la API de Ollama y el streaming directo permite reducir el tiempo de espera percibido en un 65%.

Uso de VRAM por Contexto

Distribución eficiente de la memoria de la GPU (6GB) para mantener el sistema ágil durante tareas de desarrollo intensivo.

II. Los 5 Pilares del Diseño

Arquitectura modular diseñada para la soberanía digital y el control total.

💬

Chat Playground

Inferencia multi-turno con renderizado Markdown y bloques de código funcionales.

🎛️

Hiper-controles

Ajuste quirúrgico de Temperatura, Top_P y Penalización de Repetición al vuelo.

📊

Telemetría IA

Monitorización de tokens por segundo (t/s) y estado de salud del backend en vivo.

📚

Prompt Library

Presets de sistema para transformar a Runeforge en experto de seguridad o código.

⚡

WebCommand

Puente directo a la ejecución de scripts del sistema sin abandonar la conversación.

Perfiles de Inferencia

No todos los problemas requieren el mismo enfoque. La v2.0 permite cambiar entre "Modos de Pensamiento" ajustando la estocasticidad del modelo. Un modo **Técnico** prioriza la precisión de la sintaxis, mientras que un modo **Creativo** expande el espacio de búsqueda semántica.

  • Code Master (Temp: 0.15)
  • Creative Synthesis (Temp: 0.8)

III. Ciclo de Vida de una Petición

Cómo fluye la información desde la interfaz hasta la ejecución en hardware local.

Paso 01
Input Engineering

El usuario define el prompt y ajusta los sliders de hiperparámetros.

➜
Paso 02
Context Injection

El backend inyecta memorias de 'EL_ABISMO' y el System Prompt seleccionado.

➜
Paso 03
GTX Inference

Ollama procesa la entrada en la GTX 1660 SUPER usando núcleos CUDA.

➜
Paso 04
Stream Display

La UI renderiza fragmentos de texto en tiempo real con resaltado de sintaxis.
