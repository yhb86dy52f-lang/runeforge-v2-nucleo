Guía Pasos de Flasheo e Instalación con Arduino IDE

1

Instalar Arduino IDE 2.x y Soporte para ESP32

Descarga Arduino IDE desde la web oficial. Abre Archivo > Preferencias e introduce la siguiente URL en Gestor de URLs Adicionales de Tarjetas:

https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json
2

Instalar la Plataforma ESP32 de Espressif

Ve a Herramientas > Tarjeta > Gestor de Tarjetas, busca esp32 por Espressif Systems e instálalo.

3

Conectar Hardware y Seleccionar Puerto COM

Conecta tu ESP32 por USB. En Arduino IDE selecciona la tarjeta ESP32 Dev Module y elige el puerto serie detectado (ej. COM3 o /dev/ttyUSB0).

4

Compilación y Subida (Upload)

Copia el código generado en la pestaña anterior dentro del editor, pulsa el botón Subir (→).

Módulo 06

Servidor Backend Cloud & API REST

Código Node.js / Express listo para recibir reportes de las pasarelas, indexar el hash $H(p_i)$ de la clave pública y servir los datos cifrados a la aplicación cliente.

// server.js - Backend Express API de Relevo BLE
const express = require('express');
const crypto = require('crypto');
const app = express();
app.use(express.json());

// Base de datos en memoria para reportes de ubicación cifrados
const reportsDB = new Map();

// Endpoint POST: Las pasarelas suben coordenadas cifradas
app.post('/api/v1/report', (req, res) => {
    const { keyHash, encryptedPayload, timestamp, rssi } = req.body;
    
    if (!keyHash || !encryptedPayload) {
        return res.status(400).json({ error: 'Parámetros inválidos' });
    }

    if (!reportsDB.has(keyHash)) {
        reportsDB.set(keyHash, []);
    }

    reportsDB.get(keyHash).push({
        encryptedPayload,
        timestamp: timestamp || Date.now(),
        rssi
    });

    console.log(`[CLOUD] Reporte recibido para Hash H(p_i): ${keyHash.substring(0, 10)}...`);
    res.status(200).json({ status: 'SUCCESS' });
});

// Endpoint GET: El propietario consulta los reportes de su baliza
app.get('/api/v1/reports/:keyHash', (req, res) => {
    const { keyHash } = req.params;
    const reports = reportsDB.get(keyHash) || [];
    res.json({ keyHash, count: reports.length, reports });
});

app.listen(3000, () => console.log('Servidor Cloud escuchando en puerto 3000'));

Estructura del Payload POST HTTP

Cuando una pasarela móvil captura el anuncio del ESP32, empaqueta los datos y realiza la siguiente solicitud JSON cifrada al servidor:

"keyHash": "e3b0c44298fc1c1..."
"encryptedPayload": "a9f82c..."
"timestamp": 1728130000
"rssi": -68
Garantía de Privacidad: El servidor almacena los datos indexados solo por el hash. Jamás conoce las coordenadas en texto plano ni la identidad del usuario.
