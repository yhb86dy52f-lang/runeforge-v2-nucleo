# 🏛️ RUNEFORGE V2.6.2 — MANIFESTO DE ARQUITECTURA

## Filosofía del Sistema
- **Local-First:** Cero dependencias de la nube para la operación táctica.
- **Privacidad Radical:** Los datos no salen del dispositivo.
- **Cero Bloat:** Uso de Vanilla JS y Canvas nativo en lugar de librerías pesadas.
- **Estética Cyber-Mística:** Dark mode, acentos neón y Glassmorphism.

## Ecosistema Modular (V25 FINAL)
El Command Center Táctico se compone de 4 módulos integrados en un único HTML offline:
1. **DB (IndexedDB):** Almacenamiento ilimitado de tramas de telemetría.
2. **Charts (Canvas):** Graficación en tiempo real sin librerías externas.
3. **Live (Simulador):** Flujo continuo de datos para pruebas de estrés.
4. **Mapa (Leaflet):** Geolocalización táctica con filtro oscuro.

# RUNEFORGE V2 CORE — La Fábrica de Aplicaciones

## ¿Qué es esto?
Es un ecosistema modular para crear, monitorear y gestionar herramientas de telemetría y automatización, sin depender de internet.

## ¿Qué es el NEXUS TACTICAL V25?
Es tu Command Center definitivo. Un solo archivo HTML (ubicado en C:\RUNEFORGE_V2_CORE\index_master_V25_FINAL.html) que contiene:
- **Simulador de Flota:** Genera datos de prueba cada 2 segundos.
- **Mapa en Vivo:** Rastrea la posición de la unidad.
- **Gráficas Canvas:** Dibuja el voltaje y el combustible en tiempo real.
- **Base de Datos:** Guarda todo el historial sin usar internet.

## ¿Cómo se usa?
1. Abre index_master_V25_FINAL.html en tu navegador.
2. Ve a la pestaña LIVE y presiona "INICIAR SIMULADOR".
3. Explora las pestañas MAPA, GRÁFICA y DB para ver la magia.

## Beneficios de la Limpieza
Hemos liberado **15 GB** de espacio eliminando instaladores viejos y backups redundantes. El disco C:\ ahora está optimizado.
