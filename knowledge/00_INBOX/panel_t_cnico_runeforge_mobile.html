Núcleos Duales: a-Shell vs iSH

Análisis de los dos entornos principales. a-Shell actúa como el cerebro táctico para operaciones de alta velocidad, mientras que iSH proporciona compatibilidad Linux completa para herramientas que no existen en el entorno nativo de iOS.

a-Shell (Holzschuch)

Ejecución nativa ARM64. Ideal para orquestación de tareas, Python 3.13 avanzado y gestión de red SSH rápida.

  • ✔ Acceso nativo a Python (Numpy/Scipy incluido)
  • ✔ Soporte Shortcuts (In-Extension/In-App)
  • ⚠ Sandbox estricto: Acceso solo a ~/Documents
# Comando de Orquestación
ssh nesthor@100.111.32.10 'powershell.exe'

iSH (Alpine Linux)

Emulación x86 en espacio de usuario. Proporciona un entorno Alpine completo con gestor de paquetes apk.

  • ✔ Gestor de paquetes 'apk' completo
  • ✔ Truco /dev/location para segundo plano
  • ✖ Rendimiento bajo (3x-5x más lento)
# Instalación de herramientas
apk add nmap gcc make git

Laboratorio de Scripts

Implementaciones tácticas listas para usar. Estos scripts han sido optimizados para evitar errores de interpretación en el portapapeles de iOS mediante sintaxis "single-line" y manejo de rutas locales del sandbox.

1. Auditoría del Nodo RUNE (a-Shell)

Genera un reporte forense en JSON con IP de Tailscale y espacio libre, dejándolo en el portapapeles de iOS.

echo '#!/bin/sh' > ~/Documents/RUNEFORGE_BASES/scripts/audit_rune.sh && echo 'IP=$(ifconfig | grep inet | grep "100." | awk "{print \$2}")' >> ~/Documents/RUNEFORGE_BASES/scripts/audit_rune.sh && echo 'SPACE=$(df -h | grep /private/var | awk "{print \$4}")' >> ~/Documents/RUNEFORGE_BASES/scripts/audit_rune.sh && echo 'echo "{\"ip\":\"$IP\", \"space\":\"$SPACE\"}" > ~/Documents/RUNEFORGE_BASES/output/audit.json' >> ~/Documents/RUNEFORGE_BASES/scripts/audit_rune.sh && chmod +x ~/Documents/RUNEFORGE_BASES/scripts/audit_rune.sh
2. Sincronización Segura (iSH Rsync)

Utiliza el montaje 'ios-unsafe' para prevenir bloqueos de File Provider durante transferencias masivas.

#!/bin/sh
trap 'umount /mnt/shared 2>/dev/null' EXIT
mkdir -p /mnt/shared
mount -t ios-unsafe . /mnt/shared
rsync -rtP /mnt/shared/logs/ nesthor@100.111.32.10:D:/BACKUPS/
