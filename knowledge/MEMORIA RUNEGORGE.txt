RUNEFORGE_MASTER_FUSIONADO

Núcleo:
- Runeforge es un ecosistema personal local-first
- PC Windows = backend principal
- iPhone = consola ligera
- Tailscale = red privada
- WhatsApp / Atajos / otros = canales, no núcleo

Principios:
- backend primero, interfaz después
- modular
- seguro por defecto
- lógica desacoplada de UI y canales
- usar API específica o solución local según convenga
- evitar complejidad prematura

Módulos:
- Core
- Beacon
- Forge
- Relay
- Codex
- Trace
- Sentinel
- Anvil
- adapters/
- Vault

Stack por defecto:
- Windows
- PowerShell 7
- VS Code
- Node.js
- Git / GitHub
- Tailscale
- iPhone como cliente/consola
- WSL / Python / Docker solo si aportan valor real

Reglas de implementación:
- no empezar por bots si aún no existe backend útil
- no hacer dependencias centrales de integraciones externas
- no priorizar visual sobre operación real
- preferir endpoints, paneles, acciones controladas y scripts claros
- escalar por módulos/adapters sin rehacer base

Seguridad:
- .env para secretos
- no hardcodear llaves
- no exponer secretos en frontend
- priorizar acceso privado por Tailscale
- si una key se expone, rotación inmediata
- para acciones sensibles, usar listas permitidas o acciones controladas

Formato obligatorio de respuesta:
1) Resumen corto
2) Pasos concretos
3) Texto copiable
4) Validación esperada
5) Siguiente paso recomendado

Integración a-Shell:
- a-Shell / a-Shell mini = consola táctica ligera en iPhone
- no sustituye backend principal
- ideal para:
  - validación rápida
  - edición ligera
  - pruebas pequeñas
  - inspección
  - ejecución controlada
- no ideal para:
  - backend persistente
  - flujos largos
  - edición compleja multi-línea
  - construcción pesada del proyecto

Reglas a-Shell:
- comandos por separado
- método:
  1) pegar
  2) Enter
  3) esperar salida
  4) siguiente
- crear archivos con:
  - echo 'línea' > archivo
  - echo 'línea' >> archivo
- validar con:
  - cat archivo
- permisos:
  - chmod +x archivo
- ejecutar:
  - ./archivo
- evitar:
  - edit
  - printf
  - cat > archivo salvo necesidad

Regla final:
- al terminar análisis/pruebas, evaluar si se puede entregar ZIP listo para usar
