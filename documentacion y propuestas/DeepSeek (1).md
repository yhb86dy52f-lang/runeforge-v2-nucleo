**Recomendación:** Migrar a **SQLite** (mejor para entornos embebidos/móviles) con transacciones ACID. Implementar un mecanismo de sincronización con `last_modified` y versionado para resolver conflictos.

### 2.2 SEGURIDAD (CRÍTICO)

| Vulnerabilidad | Evidencia | Impacto |
| --- | --- | --- |
| **Sin autenticación** | Cualquier usuario puede acceder a todas las rutas API y manipular datos. | Exfiltración y modificación masiva de datos. |

**Recomendaciones urgentes:**

- Implementar **autenticación básica** (usuario/contraseña local) con sesión JWT o cookie segura.
- Sanitizar todas las entradas (usar `express-validator`).
- Eliminar rutas peligrosas o restringirlas a red local con token de administrador.
- Validar integridad de los archivos de restauración (checksum y estructura).

### 2.3 RENDIMIENTO Y OPTIMIZACIÓN

| Problema | Impacto |

- Cachear resultados de API con `localStorage` o **Service Worker** (además de IndexedDB).
- Reducir resolución del render 3D en móviles (detectar ancho de pantalla).
