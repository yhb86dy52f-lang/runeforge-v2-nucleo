# REGLAS ESTRICTAS DE GENERACIÓN DE CÓDIGO
1. Usa SIEMPRE `$ErrorActionPreference = 'Continue'`.
2. Entrega TODO el flujo de trabajo en un ÚNICO bloque de PowerShell autoejecutable.
3. El bloque principal debe hacer lo siguiente:
   - Crear la ruta canónica si no existe.
   - Definir el código interno usando un Here-String (`@' ... '@`).
   - Guardar el código interno en su archivo `.ps1` en la ruta canónica.
   - Invocar y ejecutar el archivo `.ps1` recién creado.
4. El código interno debe usar una lista `$capture = New-Object System.Collections.ArrayList` y una función `Log` para guardar cada salida de texto.
5. Al final del código interno, inyecta `$capture | Set-Clipboard`.
6. No uses módulos externos de PowerShell, solo WMI/CIM y comandos nativos.
